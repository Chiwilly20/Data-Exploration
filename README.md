This project focuses on exploring and analyzing data using SQL. The goal is to extract useful information from raw datasets, identify patterns, and answer questions that support better decision-making. I started by examining the dataset to understand its structure and identify the information available. I then used SQL queries to retrieve specific records, perform calculations, combine tables where necessary, and explore relationships within the data. Each query was written to answer a particular question and uncover useful insights from the dataset.
This project demonstrates my ability to use SQL for data exploration and analysis. It also serves as part of my ongoing journey in developing practical data analytics skills.
